# User stories

| # | Description | Goal(s) |
|-|-|-|
| 1 | As an admin, I want CRUD functionality for show ticket one-time purchases. | Build a `Show()` class to model CRUD functions for admins. |
| 2 | As a user, I want to be able to purchase show tickets. | Build a `Show()` class to model CR functions for admins. |
| 3 | As an admin, I want CRUD functionality for student lesson purchases. | Build a `Lesson()` class to model CRUD functions for admins. |
| 4 | As a verified user, I want to be able to purchase a subscription to dance lessons. | Build a `Subscribe()` subclass on `Lesson()` to model CRUD functions for verified users. |


## Future plans

- As a verified user, I want to be able to pay for lessons.
- As a new user, I want to be able to attend a taster lesson without paying for a subscription.
- As a user, I want to be able to purchase school uniforms.
- As a user, I want to be able to purchase equipment.
- As a user, I want to be able to purchase upcoming show tickets!
